# Armazenamento local

O índice Chroma, o cache do modelo de embeddings e os checkpoints SQLite ficam nesta pasta. A criação do índice é explícita no notebook. Cada nova investigação recebe um identificador próprio. Abrir um checkpoint salvo apenas lê o resultado; a retomada exige a decisão humana vinculada à versão apresentada. Estes dados e as credenciais não são material para publicar no Git.
